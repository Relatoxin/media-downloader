# Demo guide

Use only a video you own or a synthetic/local HLS fixture.

## 60-second recording script

1. Show the desktop app and the selected output directory.
2. Start an authorized video in Chrome and open the extension.
3. Point out the preview, duration, resolution, and visible-card count.
4. Add the card and show the desktop window being restored.
5. Choose a video format or audio-only output and start the job.
6. Cancel one short test to show partial-file cleanup.
7. Complete a second test and use **Открыть в проводнике** to highlight the file.
8. End on the architecture diagram and test results.

Before publishing, blur account names, browser profiles, local paths, private URLs, cookies, tokens, and unrelated tabs. Do not demonstrate DRM-protected or copyrighted third-party content without permission.
